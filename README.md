# CRUD PHP - SiteGames 🎮

## Sobre o projeto

O **CRUD PHP - SiteGames** é um projeto voltado ao desenvolvimento de uma aplicação web relacionada ao universo dos jogos, utilizando PHP para praticar conceitos de programação e manipulação de dados.

O projeto tem como objetivo aplicar conhecimentos de desenvolvimento web, explorando operações de cadastro, consulta, atualização e exclusão de registros, conhecidas como CRUD (*Create, Read, Update e Delete*).

## Objetivos

- Praticar o desenvolvimento de aplicações web com PHP.
- Compreender o funcionamento das operações CRUD.
- Aplicar conceitos de programação no desenvolvimento de um sistema web.
- Desenvolver habilidades de organização e manipulação de dados.

## Tecnologias utilizadas

- **PHP:** implementação da lógica da aplicação no servidor.
- **HTML:** estruturação das páginas web.
- **CSS:** estilização da interface.
- **Banco de dados:** utilizado caso esteja configurado no projeto.

## O que é CRUD?

CRUD é um conjunto de quatro operações básicas utilizadas para gerenciar informações em uma aplicação:

- **Create:** criação de registros.
- **Read:** consulta e visualização de registros.
- **Update:** atualização de informações existentes.
- **Delete:** exclusão de registros.

## Como acessar o projeto

O código-fonte está disponível no GitHub:

```bash

```

Para executar a aplicação, pode ser necessário configurar um ambiente local com PHP e, caso utilizado pelo projeto, um banco de dados.
